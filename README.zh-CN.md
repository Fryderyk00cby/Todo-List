# Todo List

## 日历备忘录

顶部新增 **备忘录（Memo）** 标签页：左侧是跟随主题配色的月历，右侧记录当天的重要事项。有备忘的日期显示圆点，今天会高亮。点击日期即可编辑；使用左右按钮切换月份，点击 **今天** 回到当天。日历获得焦点时，也可以用方向键选择日期、回车进入编辑。

支持多行内容，每天最多 4,095 个 UTF-16 代码单元。停止输入片刻后自动保存，切换日期、离开栏目和关闭窗口前也会保存。清空当天内容即可删除该日备忘。保存失败时会显示提示，并保留当前输入以便重试。

数据保存在程序旁的 `memos.dat`（UTF-8 文本），备份时请一并保留。恢复出厂设置也会清空备忘录及 `memos.dat.tmp` 临时文件。

轻量级 Windows 原生待办工具，使用 **C + Win32** 编写。编译后得到单个 `todo_list.exe`，无需安装 Python、.NET 或其他运行环境。

**其他语言：** [English](README.en.md) · [项目首页](README.md)

## 功能特性

- **手动补录专注** — 在 **专注时间** 页点击 **手动补录**，填写内容及开始、结束日期时间后保存。支持补录过去 1 分钟至 31 天的时间段，跨午夜按日期拆分，自动计入每日和每周统计。重叠记录会分别累计，请避免重复补录。
- **增删改查** — ListView 列表界面，支持添加、完成、删除任务
- **截止日期** — 可选 Due 日期选择器；未完成且已过期时在 Due 列显示为红色
- **工作计时** — 顶部 **Focus time** 标签页：输入工作内容、开始/停止计时，自动记录时段
- **工作历史** — 查看任意日期的总工作时长与各条记录（时间段、时长、内容）
- **自动保存** — 写入程序同目录下的 `todos.dat` 与 `study.dat`（工作记录，纯文本，可手动编辑）
- **零依赖** — 单个 `.exe`，拷贝整个文件夹即可备份或迁移
- **快捷键** — Enter 添加、Delete 删除，菜单中亦有对应项

## 个性化外观

- **中英文切换**：在 **Settings（设置）→ Language / 语言** 中选择 **English** 或 **简体中文**，界面立即切换。语言保存在程序目录的 `settings.ini`，重启后恢复，默认使用英文；任务内容和正在进行的专注计时不受影响。
- **Daylight 工作台**：柔和背景、圆角卡片、宽松行距，以及按钮悬停和键盘焦点反馈。
- **三套主题**：点击右上角齿轮打开 **Settings**，在 **Appearance** 中选择 **Sage（鼠尾草绿）**、**Lavender（薰衣草紫）** 或 **Apricot（暖杏色）** 预览卡片，即时应用到所有视图。
- **独立设置页**：点击 **Back** 或按 **Esc** 返回原页面。设置页面的控件、布局和绘制集中在 `src/settings.c` / `src/settings.h`，便于继续添加设置项。
- **自动记忆**：主题保存在程序目录的 `appearance.ini`，重新打开后沿用。
- **进度概览**：顶部显示待办数、已完成数 / 全部任务数、完成进度条及当天已保存的专注时长（不含正在计时的会话）。
- **专注空间**：**Focus time** 页使用独立计时卡片；**View history → Weekly rhythm** 查看每日与每周记录。
- **键盘导航**：Tab / Shift+Tab 切换控件，Space 激活聚焦按钮，原有 Enter 添加、双击编辑和 Delete 删除继续可用。

外观代码位于 `src/appearance.c` / `src/appearance.h`，仍只依赖 Windows 原生 API，原有任务和工作记录格式保持兼容。

## 快速开始

### 恢复出厂设置

点击右上角齿轮，进入 **设置 → 数据与重置 → 恢复出厂设置**。确认弹窗默认选择“否”，选择“是”后才执行：

- 清空全部待办和专注历史（`todos.dat`、`study.dat`），以及程序残留的这两个文件的 `.tmp` 临时文件。
- 丢弃正在计时的会话和未保存的输入，清零界面统计。
- 移除 `appearance.ini`、`settings.ini`，恢复鼠尾草绿主题和英文界面。

此操作无法撤销。程序只处理上述文件，不会批量删除其他 `.dat` 文件。退出后可能重新生成空的记录文件，这是正常行为。

文件被占用或只读时会提示失败并保留原记录；若提示恢复文件未还原或未删除，请按提示处理程序目录中的 `.reset-backup` 文件。

### 环境要求

在 Windows 上需要 **任选其一** C 编译器：

| 编译器 | 常见安装方式 |
|--------|--------------|
| **gcc**（MinGW-w64） | [MinGW-w64](https://www.mingw-w64.org/) 或 MSYS2（`pacman -S mingw-w64-x86_64-gcc`） |
| **cl**（MSVC） | [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，勾选「使用 C++ 的桌面开发」 |

### 编译与运行

```bat
build.bat
todo_list.exe
```

编译完成后也可双击 **`run.bat`** 启动。

**可选：** 右键 `todo_list.exe` → **发送到** → **桌面快捷方式**。

## 使用方法

以下操作使用默认英文界面的按钮名称；切换中文后，功能和快捷键相同。

### 基本操作

| 操作 | 方式 |
|------|------|
| 添加任务 | 在输入框输入文字，可选勾选 **Due** 并选择日期，点击 **+ Add task** 或按 **Enter** |
| 标记完成 | 点击任务前的复选框 |
| 选中任务 | 点击任务行（再次点击可取消选中） |
| 编辑任务 | 双击任务行，修改后按 **Enter** 确认 / **Esc** 取消 |
| 删除任务 | 先选中一行，再点 **Delete task** 或按 **Delete** |

### 快捷键

| 快捷键 | 作用 |
|--------|------|
| **Enter**（输入框聚焦时） | 添加任务 |
| **Delete**（列表聚焦时） | 删除当前选中任务 |
| **任务 → Add Task** | 同 Add 按钮 |
| **任务 → Delete Selected** | 同 Delete 按钮 |

### 界面说明

- **顶部概览** — 显示待办数、已完成数 / 全部任务数，以及今日已保存的专注时长
- **Due 列** — 无日期显示 `-`；未完成且已过期显示为 **红色**
- **已完成任务** — 灰色文字 + 删除线
- **空列表** — 显示提示：*A fresh start. Add your first small step above.*

## 工作计时（Work）

顶部 **My tasks** / **Focus time** 按钮可切换界面。

### 计时操作

| 操作 | 方式 |
|------|------|
| 切换界面 | 点击顶部 **My tasks** 或 **Focus time** |
| 开始工作 | 输入工作内容，点击 **Start focus** 或按 **Enter** |
| 停止计时 | 点击 **Finish session**（再次点击同一按钮）；不足 1 分钟不会保存 |
| 查看历史 | 点击 **View history** |

计时进行中会显示大号时钟（`HH:MM:SS`），从 0 开始累加。未开始计时时显示当前系统时间。停止后不足 1 分钟不保存，满 1 分钟自动写入记录。

### 历史记录

| 操作 | 方式 |
|------|------|
| 返回计时页 | 点击 **Back** |
| 切换日期 | 使用 **Prev** / **Next** 或日期选择器 |
| 切换周次 | 在 **Weekly rhythm** 中使用 **Prev** / **Next**（不可跳到未来周） |
| 查看详情 | 列表显示：时间段（精确到分钟）、时长（`HH:MM:SS`）、工作内容 |
| 删除记录 | 点击选中一行，再点 **Delete Selected** 或按 **Delete** |
| 本周统计 | 点击 **Weekly rhythm** 查看本周（周一至周日）每日工作总时长柱状图 |

顶部汇总当日 **总工作时长** 与会话数量。

### 工作数据格式

`study.dat` 每行一条工作记录（UTF-8，文件名保持不变以兼容旧数据）：

```text
<日期>|<开始时间>|<结束时间>|<秒数>|<工作内容>
```

跨自然日（过零点）的计时会按天拆成多条记录：前一段结束时间为 `23:59:59`，后一段从 `00:00:00` 开始。

**示例：**

```text
2026-06-17|09:30:00|10:45:00|4500|Win32 API
2026-06-17|14:00:00|15:30:00|5400|数据结构
2026-06-17|23:30:00|23:59:59|1800|加班
2026-06-18|00:00:00|00:30:00|1800|加班
```

## 数据存储（待办）

任务会在每次变更时自动写入 **`todos.dat`**（与 `todo_list.exe` 同目录），退出程序时也会再次保存。

### 文件格式

每行一条任务：

```text
<状态>|<截止日期>|<任务内容>
```

| 字段 | 说明 |
|------|------|
| `状态` | `0` = 未完成，`1` = 已完成 |
| `截止日期` | `YYYY-MM-DD` 格式，无则留空 |
| `任务内容` | 任务描述（最多 255 个 UTF-8 字节，常用汉字通常占 3 字节） |

**示例：**

```text
0||Buy groceries
0|2026-06-15|Finish report
1|2026-06-10|Done task
```

**旧格式**（加载时仍兼容）：

```text
0|无截止日期的任务名
```

**说明：**

- 文件编码为 **UTF-8**；旧版按系统 ANSI 代码页（简体中文系统通常为 GBK）保存的文件会在加载时尝试转换
- 保存时先写入临时文件，成功后再替换原文件
- 任务文字中的竖线 `|` 保存时会被替换为空格
- 任务文字中的换行会被去掉
- 可用记事本直接编辑 `todos.dat`，重启程序后生效

## 从源码编译

修改源码后，先关闭正在运行的程序，再执行 `build.bat`。

`build.bat` 会优先尝试 **gcc**（MinGW），失败则尝试 **cl**（Visual Studio）。成功时会提示使用的编译器。

**手动使用 MinGW 编译（包含清单和图标资源）：**

```bat
windres -i app.manifest.rc -o app.manifest.o
gcc -O2 -Wall -mwindows -o todo_list.exe src/main.c src/todo.c src/study.c src/appearance.c src/settings.c src/language.c app.manifest.o -lcomctl32 -lgdi32 -luser32
```

**未找到编译器时：** 脚本会报错退出。若之前已成功编译过，现有的 `todo_list.exe` 仍可正常运行。

## 开发说明

| 项目 | 说明 |
|------|------|
| 语言 | C（C99） |
| 平台 | Windows 10 / 11 |
| 界面 | Win32 API + Common Controls（ListView、DateTimePicker） |
| 清单 | Common Controls 6.0，Per-Monitor DPI 感知 |

**设计原则：** 保持零依赖 — 最终仍是一个可独立运行的 `.exe`，不引入额外运行时或安装程序。

欢迎继续添加功能。新增特性时，按界面、存储、外观、设置和语言的职责扩展对应模块，界面文案统一放入 `language_strings.h`。
